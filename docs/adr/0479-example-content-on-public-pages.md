# ADR 0479: Example content on public pages

**Status:** Accepted, 13 Nov 2026, signed by Fadhul (CSO) in chat at GATE A of `PROMPT-LANDING-TETHER.md` (`docs/landing/gate-a-proposal.md`).

## Decision

- Every example is labelled: its accessible name starts "Example", and the hero ticket carries "This is an example ticket." (D-LP-07).
- Example dates roll: always six days ahead at 10:40, Africa/Kampala (D-LP-08).
- Real people's names appear only with written consent on file. None ship now: the doctor line shows initials (D-LP-04).
- No real patient, booking or count is read. No queue number and no promised hour (ADR 0084, D-LP-02).
- A sentence that promises a feature shows only while that feature is live: pre-alert (`FEATURE_PRE_ALERT`, D-LP-06) and SMS replies (D-LP-05).
