Component library · Tether

One set of parts for every Tether screen

The Tether Kit builds every Tether surface from the same parts, from the patient's phone to the reception desk. Behaviour comes from Base UI; the look is Tide. Each part sizes itself for patients or for the desk, so a patient and a receptionist at the same clinic see one product.

It is built one set at a time, and each set is reviewed before the next begins. Everything below is the real code, running live, dressed in Jacaranda, the palette chosen for prototyping the kit. The product keeps its shipped colours until the owner decides otherwise. Rows are examples, not patients.

Using the kit

Wrap the surface once

<KitRoot> switches the Tide tokens on and sets the density for everything inside: patient by default, desk for reception, the clinic floor and the admin.

Pass intent, not colour

Parts take a tone and a size. They own every colour, radius and motion, so a screen cannot drift from Tide.

The rules travel with the parts

A disabled button says why, a status is an icon and a word, an icon-only button is named. Tests in the repo hold each rule.

Set 1 · Actions and labels

In review

The parts on every screen: buttons, the tags that label things and carry state, and the two surfaces everything sits on.

Button Button · ButtonLink

The pill that does something. Button acts, ButtonLink navigates. Press "Send reminder" to see the busy state: the spinner only takes over after 400 ms, so quick actions never flash.

Loading the live parts…

How to use it

  • primary for the main action of a form or card. Navy in light, near-white in Navy.
  • accent (lagoon) for the one thing to do now. One per screen region.
  • soft and outline beside a main action; quiet for "Change" and "Add" in a row.
  • danger only for Help and "Get help now".
  • Use disabledReason, never a bare disabled: the reason shows under the button and is read with it.
  • Two accent buttons in one region, or danger for delete.
Example
import { Button, ButtonLink } from "@/components/tether-kit";

<Button tone="accent">Book a visit</Button>
<Button busy={saving} onClick={save}>Save reading</Button>
<Button size="m" disabledReason="Sign the discharge summary first.">
  Discharge
</Button>
<ButtonLink href="/visits" tone="outline" size="m">See your visits</ButtonLink>

IconButton IconButton

A round button with only a glyph, for the few glyphs everyone reads: close, more and the steppers. Everything else is a Button with a word.

Loading the live parts…

How to use it

  • label is required: it is read out and shown on hover.
  • Tones soft (default), outline or quiet. Never accent or danger.
  • 48 px for patients, 36 px at the desk, from the surface's density.
  • An icon-only button for anything a person has to guess.
Example
import { IconButton, ICON } from "@/components/tether-kit";
import { XIcon } from "lucide-react";

<IconButton label="Close" icon={<XIcon {...ICON} />} onClick={close} />

Tag and StatusTag Tag · StatusTag

Tag names a thing. StatusTag is the only part that carries state, always as an icon and a word, so state is never colour alone.

Loading the live parts…

How to use it

  • area adds the place dot (visits, readings, medicines, team, me). A dot beside the word, never a fill behind it.
  • stable, caution and critical are health, owned by the Clinical Safety Officer: readings and emergencies only.
  • pending for waiting, offline and loading; info for neutral notices.
  • Red, amber or green for a workflow state such as "Late".
Example
import { Tag, StatusTag } from "@/components/tether-kit";

<Tag area="visits">Visits</Tag>
<StatusTag tone="caution">Above your target</StatusTag>
<StatusTag tone="pending">Waiting for the clinic</StatusTag>

Card and Band Card · Band

The two surfaces everything sits on. A Card is the white object on the grey ground; a Band is the navy header of a ticket or a patient's record.

Loading the live parts…

How to use it

  • Card: 22 px corners and 20 px padding for patients, 18 px and 16 px at the desk. flat for a card inside a card.
  • Band text uses on-band; its one lagoon word uses on-band-accent.
  • State shows through a StatusTag inside the surface.
  • A coloured left edge, a gradient, or a Band inside a Card.
Example
import { Card, Band, KitRoot } from "@/components/tether-kit";

<KitRoot density="desk">
  <Band>…the patient's header…</Band>
  <Card>…today's visits…</Card>
</KitRoot>
